# First Project — To-Do List

My first vibe-coded project. A simple to-do list web app built with plain HTML, CSS, and JavaScript (no frameworks, no build step, no dependencies).

## Features
- Add tasks
- Click a task to mark it done (strikethrough)
- Remove tasks
- Tasks are saved in the browser (localStorage), so they persist after refreshing

## How to run it
1. Clone this repo
2. Open `index.html` in any web browser — that's it, no install needed
